# Atlas Forge Games branding

`atlas-forge-logo.jpg` is the logo supplied by the project owner as
`logo (1).jpg`. The original JPEG is included byte-for-byte, without editing,
cropping or recolouring. The game scales it proportionally when displaying it.

It appears on the startup splash and in the main-menu studio credit. Missing or
unreadable logo files fall back to a text credit so the game can still launch.
