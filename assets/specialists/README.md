# Specialist portraits

The two approved test portraits are bundled as their original square PNGs.
The UI scales and caches them at 40, 55 and 112 pixels; missing character
portraits fall back to initials. Filenames are keyed by specialist ID, so
renaming a character in the balance editor does not detach the artwork.

| Asset | Character | Art direction |
| --- | --- | --- |
| `mara_voss-v1.png` | Mara Voss | Human veteran shipyard engineer, short dark hair with silver strands, practical charcoal work jacket, amber facial light and cyan rim light, blurred shipyard. |
| `orun_basalt-v1.png` | Orun Basalt | Lithar mineral prospector, living basalt plates and crystal ridges, amber eyes and mineral veins, teal mining harness, blurred asteroid station. |

Generated using the built-in image generation tool for Orion Reach and approved
for inclusion by the user. No external reference artwork is bundled. Both
portraits use a tight head-and-shoulders composition with no text, frame or UI.
Further character art can be registered in `orion/specialist_art.py`.
