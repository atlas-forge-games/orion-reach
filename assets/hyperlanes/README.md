# Forgotten hyperlane illustration

`forgotten_hyperlane-v1.png` is an original 1536 × 1024 image generated with the
built-in `image_gen.imagegen` tool for Orion Reach on 2026-10-15. It depicts a
weathered annular portal, a luminous passage and a small Wanderer habitat ship.
The exact generation prompt is in `forgotten_hyperlane-prompt.txt`; no source
image or third-party game artwork was used. The generated PNG is unmodified.

`orion/hyperlane_art.py` scales this illustration for the project screen and
draws separate precise portal symbols and route curves for map navigation.
