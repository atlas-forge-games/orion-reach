# Megastructure artwork

Original AI-generated transparent sprites created for Orion Reach v0.60.
The game scales and reveals sections at runtime; original PNG files are preserved.

| Asset | Concept |
| --- | --- |
| `dyson_sphere-v1.png` | Open golden sphere of collector bands around a separately rendered star |
| `stellar_forge-v1.png` | U-shaped orbital shipyard, capital ship, cranes and skeletal assembly arms |
| `research_array-v1.png` | Three connected platforms with a large dish, gold mirror and antennas |
| `asteroid_network-v1.png` | Mined asteroids with embedded refineries, cranes and cargo craft |

The approved concept images and a captured system screen guided these sprites.
Shared generation direction: a single transparent PNG game sprite with detailed
miniature architecture, steel grey and gold surfaces, cyan lights, no stars,
nebula, UI, labels or background; isometric, complete subject, readable at 400 px,
with modular sections. Each generation added the subject description above.
