# Soundtrack

`distant-stars.mp3` is **Distant Stars**, supplied by the project owner for this
prototype. Embedded metadata credits **alexander_kies** and identifies Suno as
the creation tool, with a creation date of 2026-10-08.

The supplied MP3 is included unchanged: stereo, 48 kHz, approximately 4:03.
SHA-256: `f0635f8a5037faaedffb13b9c9b1a4405cbd042bc3586d7729a110001109d00b`.

The game streams and repeats the file using pygame-ce, with an initial fade-in.
The original intro and ending are retained; this is track repetition, not a
remastered seamless loop. Volume and music on/off are separate from interface
sounds and are saved in the user's preferences.

Music rights are separate from the project's source code. No separate
commercial-use licence was supplied with this asset.
