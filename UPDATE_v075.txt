ORION REACH v0.75.0 — COMBAT GEOMETRY AND SOUND

INSTALL
Close the game. Extract this ZIP into your existing v0.74 game directory,
the directory containing main.py. Merge folders and replace the included files.
This is an incremental update: the existing game and artwork are required.
No dependency changes are required. Run python main.py or python combat_simulator.py.

FEATURES
- Ship shields absorb beams. Torpedoes and missiles bypass them.
- Point defense and escorts reduce projectile damage, including bomber torpedoes.
- Full footprints: destroyer 2x1, cruiser 2x2, battleship/carrier 3x2,
  titan 3x3, mothership 4x3. Movement and deployment check all occupied cells.
- Friendly and enemy ships obstruct beams. Blocked shots are unavailable;
  mixed volleys can still launch guided torpedoes. The AI seeks clear lanes.
- Synthesized beam, missile launch, shield hit, hull impact and explosion sounds.
  Projectile impacts sound on arrival, and missed shots have no impact cue.
- Settings > Sound > Sound effects controls combat and interface sounds.

SAVES
Save format is now 53. Back up existing saves before updating; older game
versions cannot open newly written format-53 saves. Existing unfinished
battles keep one-cell layouts when loaded, preserving positions and in-flight
warheads. New battles use multi-cell hulls. The new defense rules apply to
subsequent damage calculations. Planetary strategic shields retain their
separate bombardment/invasion rules.
