AGE OF THE STARS / ORION REACH — v0.83.1 CLEAN GALAXY MAP

INSTALL
Close the game. Extract this ZIP over v0.83 into the folder containing
main.py, orion/ and assets/. Replace the included files, then launch normally
with python main.py. This is an incremental update, not a complete game.

CHOOSE THE MAP STYLE
Settings > Interface > Galaxy map style > Clean / Classic
The setting applies immediately and is remembered between sessions.
Clean is the default for new and existing preferences without a saved choice.

CLEAN
- Small faction-colored fleet silhouettes with generous invisible click areas.
- Smaller, regular-weight system names, retaining known ownership colors.
- No fleet badges or map ship-count numbers; click a fleet for full details.
- No label, fleet, sensor-contact or threat connectors, travel lines or
  hyperlane connection lines. Discovered hyperlane portal markers remain.
- Small sensor diamonds; contact size and intelligence remain in the panel
  opened by clicking a contact. Sensor coverage keeps its faint shading.
- Existing selection, fleet orders, zoom, pan and fog-of-war rules still apply.

CLASSIC
The previous labels, boxed fleet counts, connecting lines and ship miniatures
remain available. A busy-map capture was pixel-identical to the v0.83 original.

No campaign restart, dependency changes or save-format migration is needed.
Four actual game screenshots and a repeatable preview script are included.
The generated concept shown in chat is a design preview, not a game asset.

VALIDATION
See docs/galaxy-map-styles.md for checks and the three gameplay-test failures
reproduced with the unmodified v0.83 baseline. No additional failures were
introduced in the map regression run. No files were committed or pushed.
