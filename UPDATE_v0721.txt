Orion Reach v0.72.1 - Categorized settings
18 October 2026

INSTALL
Extract this incremental update over your complete v0.72.0 game folder, next
to main.py. Replace the included files. No files need deleting.
Start with python main.py as before.

WHAT CHANGED
Settings now opens an overview with four categories:
- Graphics: fullscreen, animated background and galaxy background.
- Sound: background music, music volume and interface sounds.
- Gameplay: autosave, plus manual-save and new-game guidance.
- Interface: galaxy colors and a navigation reference.

Use the sidebar to switch between categories. Back or Esc returns to the
category overview, then to the screen you came from. Done returns directly
to the main menu or paused game. Opening Settings starts at its overview.
Mouse, Tab, Up/Down and Enter navigation are supported.

All existing preferences apply and save immediately. Saved preferences and
campaign saves remain compatible; no migration or reset is needed.
Battles remain paused throughout Settings and its categories.
